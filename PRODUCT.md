# Product Context: Syed Muhammad Yahya Portfolio

Personal developer portfolio for Syed Muhammad Yahya — Backend & Full-Stack Developer, Data Science & AI.

## Purpose

Showcase authentic, production-capable software engineering and applied data science. Provide technical recruiters, engineering managers, and clients with verifiable proof of engineering ability, architecture skills, and coding standards directly backed by live GitHub repositories and running services.

## Primary Audience

- Engineering leaders and hiring managers seeking backend-heavy full-stack engineers or applied data scientists.
- Technical recruiters looking for verified talent with real experience in Node.js, PostgreSQL, React, Python, and FastAPI.
- Collaborators and clients looking for robust API and full-stack system implementation.

## Value Proposition

- **Verified Code Over Claims**: All showcased projects link to real GitHub repositories with commit histories, tests, and documentation. No fabricated credentials or superficial demo wrappers.
- **Backend & Data First**: Emphasizes the unglamorous, critical parts of software — relational database integrity, foreign key constraints, connection pooling, layered middleware, auth validation, and packaging ML models into production API endpoints.
- **End-to-End Craft**: From database schema design to responsive React frontends and model deployment, every application is complete and functional.

## Core Stack & Capabilities

- **Backend**: Node.js, Express.js, REST APIs, JWT & cookie-based authentication, role-based access control, validation middleware, error handling, rate limiting.
- **Databases**: PostgreSQL, Supabase, relational schema design, transactions, Row Level Security, parameterized SQL.
- **Frontend**: React, Vite, modern CSS, accessible components, responsive design.
- **Data Science & ML**: Python, NumPy, Pandas, Scikit-learn, Matplotlib, Seaborn, exploratory data analysis (EDA), feature engineering, model evaluation.
- **Deployment & Architecture**: FastAPI (model serving), Railway, Vercel, Neon, Git/GitHub, Redis & background queue concepts.

## Design Identity & Tone

- **Voice**: Direct, grounded, technically articulate, and honest. Zero AI-generated clichés, buzzwords, or pretentious manifestos.
- **Aesthetic**: Impeccable Neo-Kinpaku system. Deep warm lacquer black surfaces, kinpaku gold accents, verdigris patina states, and clean 1px hairline borders.
- **Quality Floor**: No AI slop (no generic gradients, side-tab borders, overused fonts, bounce animations, or decorative halos). All touch targets $\ge$ 44px, strict WCAG AA/AAA contrast.
